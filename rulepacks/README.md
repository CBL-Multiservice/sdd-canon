# rulepacks/

Curated sensor rulepacks (SAST and friends) land here, produced by the
`quality-canon` exporter from the ArchGenerator producers — one source, two
consumers (assessment engine and SDD kits).

**Empty at seed (v0.1.x) — honestly.** Nothing is listed until the exporter
ships; a placeholder rulepack would be scored ballast, not content.

License red line (non-negotiable): only permissive sources, attribution
preserved per rule, Commons Clause and any non-commercial/restrictive clause
FORBIDDEN. Every rulepack arrives with its per-rule provenance manifest.
